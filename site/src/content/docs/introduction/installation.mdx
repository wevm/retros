# Installation

Retros is one binary with no runtime. Release builds cover macOS and Linux on arm64 and x64, and Cargo builds it anywhere Rust runs.

> [!NOTE]
> The first release is not published yet. Until it is, the install script, `npx retros`, and the release archives have nothing to download, and Cargo is the only way to install Retros.

## Install Script

The install script downloads the release archive for the machine, checks its SHA-256 digest against `sha256sums.txt`, and puts the binary in `~/.retros/bin`. It runs on macOS and on Linux with glibc or musl.

```sh
# Install the latest release to ~/.retros/bin/retros.
curl -fsSL https://raw.githubusercontent.com/wevm/retros/main/install.sh | sh
```

If `~/.retros/bin` is not on `PATH`, the script prints the line to add to the shell profile. Two environment variables change what it installs:

- **`RETROS_VERSION`:** The release to install, such as `0.1.0`. The default is the latest release.
- **`RETROS_INSTALL`:** The install directory. The binary goes to its `bin` directory. The default is `~/.retros`.

```sh
# Install release 0.1.0 to /opt/retros/bin/retros.
curl -fsSL https://raw.githubusercontent.com/wevm/retros/main/install.sh | RETROS_VERSION=0.1.0 RETROS_INSTALL=/opt/retros sh
```

## npm

The `retros` package runs the binary from one platform package, such as `@retros/linux-x64-gnu`. npm installs only the platform package that matches the machine's operating system, CPU, and C library, so an install downloads one binary.

```sh
# Run the latest release without installing it.
npx retros

# Or add it to a project, and run it from a package script.
npm install --save-dev retros
```

`pnpm dlx retros` and `bunx retros` run it the same way. An install that omits optional dependencies has no platform package, and `retros` then exits with an error that names the missing package.

## Cargo

Cargo builds Retros from source on any platform that Rust supports. The `--locked` flag builds with the dependency versions in the repository's `Cargo.lock`.

```sh
# Build the main branch and install it to ~/.cargo/bin.
cargo install --locked --git https://github.com/wevm/retros retros
```

## Release Archives

Each GitHub Release has one `retros-<target>.tar.gz` archive per target and a `sha256sums.txt` file. Each archive holds the `retros` binary.

| Target | Platform |
| --- | --- |
| `aarch64-apple-darwin` | macOS on Apple silicon |
| `x86_64-apple-darwin` | macOS on Intel |
| `aarch64-unknown-linux-gnu` | Linux on arm64 with glibc 2.28 or later |
| `x86_64-unknown-linux-gnu` | Linux on x64 with glibc 2.28 or later |
| `aarch64-unknown-linux-musl` | Linux on arm64, static |
| `x86_64-unknown-linux-musl` | Linux on x64, static |

The musl builds link statically, so they also run on Alpine and on systems with a glibc older than 2.28. The install script selects them on those systems, and the npm package selects them on musl.

```sh
# Download the static x64 build, check its digest, and extract the binary.
curl -fsSLO https://github.com/wevm/retros/releases/latest/download/retros-x86_64-unknown-linux-musl.tar.gz
curl -fsSLO https://github.com/wevm/retros/releases/latest/download/sha256sums.txt
grep ' retros-x86_64-unknown-linux-musl.tar.gz$' sha256sums.txt | sha256sum -c -
tar -xzf retros-x86_64-unknown-linux-musl.tar.gz retros
```

## Check the Install

`retros --version` prints the installed version.

```sh
# Print the version.
retros --version
```
