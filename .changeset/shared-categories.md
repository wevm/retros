Merged categories with the same name. The packs moved their metrics into shared categories, such as `correctness`, `style`, `documentation`, and `testing`, and each category scored once across the project and its packs. A metric that two packs declared took the items of both scripts, and a project category added its own metrics with its own script. The web pack ran the project's `build` script before it read `dist/`.
